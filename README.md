# AI Maze-Solving Robot 🤖🧩

An autonomous robot that maps unfamiliar mazes, builds a grid representation, and computes the optimal path using AI graph-search algorithms (BFS / A*).

---

## 🛠️ Hardware Stack
* **Processing:** Raspberry Pi 4 / 5 (or Raspberry Pi Pico)
* **Sensors:** Ultrasonic sensors (HC-SR04) or Infrared (IR) grid sensors for wall detection
* **Actuation:** 2-Wheel Differential Drive with DC Motors & L298N Driver
